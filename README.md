# 记账助手

面向加拿大小企业主和个体经营者的收据记账 MVP。用户可以上传收据图片，在浏览器中识别商家、日期、金额、GST/HST、PST 和费用类别，核对后保存到本地，并导出 CSV 或 Excel。

## 本地运行

需要 Node.js 18 或更高版本：

```bash
npm start
```

打开 `http://localhost:4173`。也可以直接点击“试用示例收据”体验完整流程。

## 检查

```bash
npm run check
```

## 部署到 Vercel

这是一个无构建依赖的静态网站。将项目导入 Vercel 后使用默认设置即可部署。

## 数据与识别说明

- 记录保存在当前浏览器的 `localStorage` 中，不会自动同步到其他设备。
- 收据文字识别通过浏览器端 Tesseract.js 完成。首次识别时需要联网加载识别资源；资源不可用时，页面会创建可手动核对的草稿。
- 示例收据使用内置结果，方便在没有网络时演示上传、核对、保存和导出流程。
- 分类和 GST/HST 结果是记账建议，不构成税务意见。
